# ADR-011 — ZIP reader for ZDPS v1 packages

- **Date:** 2026-10-12
- **Title:** Pinned `@zip.js/zip.js@2.23.0` native entry for declarative plugin archives
- **Status:** accepted for ZIP import and export only, after the owner’s security gate passed
- **Context/problem:** Phase P04 must read and write untrusted `.zplugin` ZIP packages. The production dependency set had no ZIP library. node-forge is not an acceptable ZIP implementation. The owner authorized `@zip.js/zip.js@2.23.0` only if a pre-install gate found no new vulnerability, license incompatibility, unsupported API, or CSP incompatibility.
- **Browser targets + tested versions:** Firefox and Chrome MV3 extension pages. CSP stays `script-src 'self'; object-src 'none'`. This ADR does not change extension identities, permissions, CSP, or Home/New Tab mappings.
- **Options evaluated:**
  1. Use `@zip.js/zip.js@2.23.0` through its documented native JavaScript entry, with workers and WebAssembly disabled.
  2. Use the package’s default WebAssembly entry or another ZIP library or version.
- **Official references:** Owner authorization on 2026-10-12. Package metadata for `@zip.js/zip.js@2.23.0` (BSD-3-Clause, no runtime dependencies). Entry export `./index-native.js`.
- **Decision:** Option 1. Venus imports `@zip.js/zip.js/index-native.js` only. `configure({ useWebWorkers: false, useCompressionStream: true })` is set before read or write. `wasmURI` stays unset on that entry (`null` in the native module). The reader uses strict filename validation, CRC-32 checks, signature checks, and overlapping-entry checks, then Venus enforces the owner’s path, size, and compression budgets before and during decompression. The writer emits archives that the same reader accepts. No other ZIP library or version is approved.
- **Why:** The native entry is the documented CSP-compatible path. It does not require `wasm-unsafe-eval`, `unsafe-eval`, a remote worker, or a remote script. The lockfile pin has no transitive dependencies. Production `npm audit --omit=dev` reported zero vulnerabilities. The full-tree audit stayed at the pre-existing high findings (`node-forge` via `@devicefarmer/adbkit`, `web-ext`, and `wxt`). No new advisory was introduced. The BSD-3-Clause text requires the copyright notice and disclaimer in source and binary distributions and forbids using the author’s name for endorsement. `licenses/zip.js/LICENSE` is a verbatim copy.
- **Impact on owner-approved FR / privacy / security:** Imported archives remain untrusted data. This ADR does not authorize plugin JavaScript, WebAssembly, HTML, CSS, or expression execution. It does not approve ADR-001, ADR-002, ADR-003, ADR-005, ADR-006, ADR-007, or the node-forge residual risk. ADR-004, ADR-008, and ADR-010 are unchanged.
- **Fallback/mitigation:** If the native entry, the pinned version, or the CSP assumption fails, ZIP import and export stop. A different library or version needs a new owner decision.
