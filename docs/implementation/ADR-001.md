## Current evidence update (2026-10-09)

The remediation report and evidence/P00/remediation supersede the earlier source's execution claims below. Firefox now invokes BrowserCommands.openTab in an isolated offline profile. The scheduler uses extension storage.session to distinguish a fresh browser session from a worker wake, with handlers gated behind initialization; DB name/schema and extension ID are unchanged. Minimum 140.0 is supported by API documentation but remains runtime NOT VERIFIED.

Owner decision proposal: retain minimum 140.0 only after running the minimum-version checklist, or explicitly approve minimum 155.0.1 for the initial desktop target because that is the exact version with execution evidence. This proposal has not changed strict_min_version or certified ESR. Review full native API/Home lifecycle results before selecting the production target. CI target provisioning is separated; hosted CI still requires run evidence. Status remains proposed; owner signature/date: PENDING.

Both explicit MV3 builds, generated manifest audit and isolated installed-extension New Tab smoke pass. Firefox uses background.scripts; Chromium uses background.service_worker. No host permissions or remote scripts are declared. Chromium smoke explicitly enables its browser security sandbox. Regular installation consent, Home restoration, API lifecycle, minimum Firefox 140 and hosted CI remain unverified. Status remains proposed; no owner sign-off is inferred.
