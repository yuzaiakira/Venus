# چک‌لیست پذیرش محصول توسط مالک

این چک‌لیست برای پایان توسعه واقعی است؛ در زمان تحویل این PRD هیچ گزینه‌ای اجرا/پاس نشده است.

- [ ] افزونه روی Firefox واقعی نصب و صفحه New Tab را جایگزین می‌کند.
- [ ] وضعیت Home و محدودیت تغییر آن صادقانه نمایش داده می‌شود و رفتار موردنظر در مرورگر هدف آزمایش شده است.
- [ ] ظاهر دارک/لایت، عکس شخصی، گرادیان، بلور/شفافیت و تنظیمات بعد از ری‌استارت باقی می‌مانند.
- [ ] فارسی/انگلیسی و RTL/LTR در همه صفحات درست هستند؛ تاریخ شمسی و میلادی تست شده‌اند.
- [ ] پروفایل‌های چینش مستقل‌اند ولی یادداشت‌ها، رویدادها، تسک‌ها و بوکمارک‌ها مشترک هستند.
- [ ] تقویم با تکرار پیشرفته شمسی (از جمله اسفند و کبیسه) و میلادی و منطقه زمانی درست عمل می‌کند.
- [ ] اعلان سیستم‌عامل در حالت پشتیبانی و مرکز اعلان داخلی با Snooze و تاریخچه کار می‌کند.
- [ ] تایمر با بسته شدن تب حفظ می‌شود؛ در زمان بسته بودن کل مرورگر هشدار لحظه‌ای تضمین نشده و اعلان ازدست‌رفته ثبت می‌شود.
- [ ] یادداشت Rich Text، پوشه تو در تو، تگ، سنجاق، جست‌وجو و سطل زباله کار می‌کنند.
- [ ] بوکمارک مرورگر و بوکمارک اختصاصی هر دو در حالت لیست پوشه‌ای و آیکون سریع دیده می‌شوند.
- [ ] Quick Capture و Command Palette در MVP حاضرند.
- [ ] هر هفت بلوک Plugin Builder ساخته و Import/Export می‌شوند؛ اجرای کد خارجی ممنوع است.
- [ ] Full/Selective/Portable Backup در مرورگر تازه قابل بازیابی‌اند؛ هیچ یادآوری بکاپ به کاربر نمایش داده نمی‌شود.
- [ ] خطاهای امنیتی و داده‌ای P0 و P1 صفر هستند؛ آزمون‌ها واقعاً اجرا شده‌اند.
- [ ] نسخه بتای محدود Firefox با دفترچه راهنما و سیاست حریم خصوصی آماده است؛ خروجی Chrome MV3 هم ساخته و تست شده است.
