# Venus — بسته کامل PRD اجرایی مخصوص AI Agent

**نام محصول:** Venus Workspace  
**نسخه مشخصات:** 1.0 — مبتنی بر Product Blueprint تأییدشده v1.1  
**وضعیت:** سند اجرایی؛ نه سورس‌کد، نه نسخه منتشرشده  
**تاریخ تدوین:** 2026-10-08  
**زبان اسناد فنی:** انگلیسی برای دقت در اجرای Agent؛ این راهنما فارسی است.

## هدف

Venus Workspace یک افزونه Local-first برای Firefox (اولویت MVP) و سپس Chrome است که **تب جدید و تا حدی که مرورگر و سیاست فروشگاه اجازه می‌دهند صفحه Home** را به فضای کاری شخصی تبدیل می‌کند. طراحی فضایی/شیشه‌ای، زبان فارسی و انگلیسی، تاریخ جلالی/میلادی، ابزارهای بهره‌وری، پلاگین‌های کاربردی بدون اجرای کد خارجی و پشتیبان‌گیری دستی، هسته محصول‌اند.

## نحوه استفاده با Agent

1. به Agent فایل `agent/AGENT_MASTER_PROMPT.md` را بدهید و کل پوشه را در اختیارش قرار دهید.
2. Agent باید ابتدا `README_AGENT.md`، `docs/00_PRODUCT_CHARTER.md`، `docs/03_ARCHITECTURE.md`، `docs/09_SECURITY_THREAT_MODEL.md` و `docs/17_TRACEABILITY.md` را بخواند.
3. توسعه طبق فازهای `phases/P00` تا `P06` است؛ ورود به فاز بعد مشروط به معیارهای خروج هر فاز است.
4. هر قابلیت باید به شناسه FR و تست قابل اجرا نگاشت داشته باشد؛ `qa/TEST_MATRIX.csv` و `qa/AGENT_TASK_BACKLOG.csv` فهرست قابل پیگیری‌اند.
5. Agent مجاز نیست برای ساده‌تر شدن کار، قابلیت‌های تأییدشده را بی‌اجازه حذف کند یا ادعای تستی را بدون اجرای آن مطرح کند.
6. پروژه باید با داده‌های ساختگی و بدون اکانت، اینترنت یا سرور قابل استفاده باشد. بسته شدن مرورگر نباید داده‌های ذخیره‌شده را پاک کند؛ هشدار زمانی که مرورگر کاملاً بسته است تضمین‌پذیر نیست.

## مسیر مطالعه

- `docs/00` تا `docs/02`: چشم‌انداز، قابلیت‌ها، UX و رفتار کاربران
- `docs/03` تا `docs/05`: معماری، مدل داده و محدودیت‌های مرورگر
- `docs/06` تا `docs/08`: زمان‌بندی، پلاگین، Backup/Restore
- `docs/09` تا `docs/13`: امنیت، Design System، تست، انتشار
- `docs/14` تا `docs/17`: تصمیمات باقی‌مانده، پروتکل Agent و ردیابی الزامات
- `contracts/`: قراردادهای نمونه و JSON Schema قابل استفاده/گسترش
- `phases/`: برنامه اجرایی مرحله‌به‌مرحله با Definition of Done

## مرزهای قطعی و قابل مذاکره

**قطعی:** Firefox-first؛ Chrome-ready؛ بدون اکانت و پرداخت در MVP؛ همه داده‌های اصلی محلی؛ فارسی/انگلیسی؛ تقویم جلالی/میلادی و تکرار پیشرفته؛ یادآوری داخل افزونه و اعلان سیستم؛ Rich Text؛ بوکمارک اختصاصی و مرورگر؛ نمایه‌های چینش با داده مشترک؛ هفت بلوک امن پلاگین؛ Import/Export دستی کامل و انتخابی؛ بتای محدود قبل از انتشار عمومی.

**وابسته به محدودیت مرورگر:** تغییر Home، دکمه‌های داخل اعلان، سطح کنترل میانبرهای سراسری، رفتار اعلان‌ها در خاموش بودن مرورگر و جزئیات MV2/MV3. Agent باید دروازه سازگاری و مسیر جایگزین مستند را اجرا کند.

**خارج از MVP:** اکانت، سینک ابری، پرداخت، Marketplace سروری، اجرای JS/WASM پلاگین‌های ثالث، اپ موبایل، هوش مصنوعی، ویرایش مشارکتی، تحلیل‌گر رفتار یا تبلیغات.

## معیار پذیرش نهایی

تحویل نهایی تنها زمانی پذیرفته است که `P06` و چک‌لیست انتشار کامل شوند، آزمون‌های بازیابی داده و تقویم/اعلان عبور کنند، نمونه پلاگین مخرب رد شود، Build مرورگرها بررسی شود و بسته بتای Firefox آماده باشد. انتشار در فروشگاه توسط مالک و پس از اخذ حساب توسعه‌دهنده/تأیید فروشگاه انجام می‌شود؛ هیچ ادعایی درباره انجام آن در این بسته وجود ندارد.
